# 前端产品规格（V3 提案）

## 约束
单 HTML、无外部 CDN、原生 JS/CSS，兼容 Chromium 80，横屏 960×600 与早期 834×360，触摸优先。页卡独立 DOM，切换仅挂载当前页；避免宿主隐藏节点重叠。所有临时状态放内存；LocalStorage 只能作为可丢失缓存；IndexedDB/Service Worker/直接摄像头均不依赖。
## Client
| 页面 | 功能 |
|---|---|
| 登录/连接 | 文件选择器拍照或选取 QR；手动配置经授权的服务；账户/PIN（需服务端限流和安全认证）；清晰连接状态 |
| 消息 | 群聊、私聊、成员列表、发送状态、历史游标、错误及重试 |
| AI | 显示服务可用性；明确 @AI 或独立问答，区分排队、推理、失败、返回；不假装回答 |
| 成员 | 在线、昵称、角色，隐私友好 |
| 网络 | 连接状态、实际 RTT、重连次数，区分未知和离线 |
| 应用 | 文件、白板、投票、游戏，后续按验收开放 |
| 设置 | 会话偏好、退出、诊断；无 API Key 输入或持久化承诺 |
布局：左侧窄导航、可选会话列表、主要消息区域、底部输入；小视口折叠列表。扫码与诊断用独立页卡。使用 textContent 或安全渲染；可访问字号、按钮、滚动、错误态；不能把演示数据作为实际状态。

## Console（iPad Safari）
独立管理 UI，与客户端及 ESP32固件解耦；普通用户无管理员权限。
- 总览：在线数量、运行时长、消息计数、实测延迟。
- 成员/房间：角色、加入策略、移除/禁言、房间状态；访问和动作服务端校验。
- AI：启用状态、队列、额度、调用统计、错误分类；密钥仅写入管理端安全配置流程，不回显。
- 系统：实际内部 heap、PSRAM、Flash、Wi-Fi、重启原因、日志。
- 数据：保留期限、授权备份、清理与操作审计；默认不展示私聊内容。
所有页面目前仅设计，尚无实际服务器连接。后台只在用户明确授权的设备与网络上运行。
