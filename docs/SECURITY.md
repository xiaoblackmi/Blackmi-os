# 安全边界与公开仓库说明

本项目仅用于获得授权的设备和网络内的本地应用与通信研究。遵守设备及网络管理方策略；不提供网站代理、请求伪装、权限规避或任意目的地转发。任何外部 AI 服务都需要获得使用许可。

- API 密钥、真实用户名/PIN、Wi-Fi凭据、真实信令 SDP、个人聊天、设备唯一标识、现场照片不提交公开仓库。
- 生产服务须使用可信 TLS 及应用身份认证，校验授权，限制消息大小、请求速率、队列、内存和日志容量。不能通过关闭 TLS 或跨域安全检查换取兼容性。
- V2 临时群聊为原型；DTLS 保护单条连接，不提供经房主中继的端到端加密或可信账号认证；不要传输敏感信息。
- V3 管理员权限由服务端验证；最小权限、审计、明确数据保留期限；不默认查看私人聊天。
- AI 只接收主动提交或明确同意的内容；密钥存服务端并按需轮换，设额度，禁止任意 URL 转发。
- 公开仓库不代表代码已获整体开源许可证。内嵌第三方组件的原有版权及许可声明必须保留；项目许可证由所有者另行确定。
