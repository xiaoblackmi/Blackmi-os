# 开发历史与源码索引

记录截至 2026-11-26。依据聊天开发记录、生成的 HTML 源文件和用户实机报告。早期实验不是产品承诺。

| 阶段 | 目的与结果 |
|---|---|
| 初始星光浏览器 UI | 早期界面原型包含模拟网站、模拟日志、预设 AI 回复和 CDN 依赖；不是实际浏览器引擎或联网 AI。外部样式在设备上不稳定。 |
| Spark Pad Browser / WebView 基础检测 | 内嵌 CSS、真实 iframe 导航及环境检测；部分获准站点可显示，其他导航返回 ERR_BLOCKED_BY_RESPONSE 或 ERR_CONNECTION_REFUSED；具体拦截层未确定。 |
| Pad WebView Test V2、Lab V3 | API 能力、WebRTC 本机回环、手工 SDP 信令；WebSocket 仅预留获授权 echo 服务，不能据接口存在确认网络可达。 |
| Lab V4 | 进一步诊断、页卡与可选配套信令服务；六位房间号需真实信令服务，不等于无需服务器的固定邀请码。配套服务是实验性，不是正式账号系统。 |
| Lab V5 | 内嵌 QR 编解码、分帧、SDP 压缩、双机文本通信成功；部分布局重叠。 |
| Connect V1 | 单文件双人聊天，页卡切换只挂载当前 DOM；用户报告成功。 |
| Connect V2 | 星型拓扑，每个成员独立 PeerConnection；房主分发消息、成员名单、退出处理。用户报告 8 台压力测试无问题。 |
| Core Lab 1.0 | 六页卡：权限、存储恢复、性能、通信压力、服务端口、报告。2026-11-26 实测；最终修正摄像头与持久化假设。 |
| Connect V3 / Core / Console | 常驻 ESP32、无状态前端、独立管理终端和 AI 方案，尚未开发验收。 |

## 源文件目录约定
- client/Blackmi_Connect_V1.html：双人聊天。
- client/Blackmi_Connect_V2_Group.html：多人群聊。
- labs/Blackmi_Core_Lab.html：当前综合诊断工具。
- archive/：早期诊断、浏览器原型及实验性信令服务，按原文件名保存（以仓库实际目录为准）。
- 不混淆演示、实验、用户报告与实测截图。
- 原始照片不公开，仅转录技术结果；没有把聊天记录或个人信息写入公开仓库。

## 已知缺陷
V2 无房主迁移、永久记录、跨重启自动登录、离线消息同步、应用层可靠投递回执；历史缓存 200 条且新成员不自动同步既往历史。一次处理一个邀请。8 人上限是代码限制及用户报告实测规模，不是芯片/网络极限。桌面环境中的实际 RTC 测试曾超时，模拟传输测试通过，不能替代真机数据。
